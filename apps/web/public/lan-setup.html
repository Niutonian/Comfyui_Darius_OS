Checking the local HTTPS gateway…

1. Verify and install the public certificate

Only install the certificate from your own Darius computer. A trusted CA can certify websites, so do not install an unfamiliar one. Compare this fingerprint with the one printed on your Darius PC by scripts/start-lan-https.ps1 or the local certificate file before trusting it. An HTTP download alone does not prove authenticity.

Download Darius’s public CA certificate

iPhone / iPad
  1. Open this page in Safari and download the certificate. If prompted, allow the configuration profile download.
  2. In Settings, open Profile Downloaded (or General → VPN & Device Management), inspect the profile, and install it.
  3. Open General → About → Certificate Trust Settings and enable full trust for this Darius CA.
  4. Return to Safari and open the secure Darius address below.
Android
  1. Download the certificate. Open Settings and search for “Install a certificate” or “CA certificate.” The path varies by device.
  2. Choose the CA certificate option, inspect the downloaded certificate, and install it. Android may require your device PIN.
  3. Open the secure Darius address in Chrome. Managed devices may prevent adding certificates; ask the administrator if so.
Windows / macOS / Firefox

Import this verified CA certificate into your trusted root certificates. On Windows, use the Current User certificate store → Trusted Root Certification Authorities. On macOS, import into Keychain Access and set this certificate to Always Trust. If Firefox still reports an unknown issuer, import it in Firefox Settings → Privacy & Security → Certificates → Authorities.

2. Open secure Darius

Open secure Darius

There should be no certificate warning. If one remains, check certificate trust and that the address matches the Darius PC. Do not disable browser security.

Choose fullscreen voice, select Pipecat, and allow microphone access when prompted. If blocked, use this site's browser permissions to allow Microphone and reload. Your normal localhost address continues to work.

Useful notes

Your HTTPS browser has its own site storage, so you may need to select your project and voice preferences again. Existing chats and assets remain on the same server. Keep both devices on the same trusted LAN. No public tunnel or router port forwarding is needed.

Reserve your Darius computer’s LAN address in the router if possible. If it changes, rerun the gateway setup for the new address. Do not share anything from data/lan-https except its public certificate.
