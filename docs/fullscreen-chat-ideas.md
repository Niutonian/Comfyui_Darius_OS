# Fullscreen conversation and saved ideas

Use **Fullscreen chat** to discuss a project with a persistent text composer. It opens without activating the microphone. **Fullscreen voice** retains the existing voice session, and the Chat / Voice controls switch presentation within the same conversation. Chat keeps the history visible and follows incoming messages unless the user scrolls back. The user can prepare their next thought while a reply is pending; completion does not erase that next draft. Existing attachment review and reply error handling remain available.

Use **Save idea** on a complete prompt card or assistant reply. Review its title and text, then choose **Save to Create**. A saved concept appears under **Create → Ideas**, where it can be searched, copied, archived and restored. Saving is explicit, project-scoped and idempotent across retries. The reviewed wording is saved as entered, with its source message and text snapshot. Saving does not create a character, scene, board, workflow or render job. **Use in board** remains a separate prompt-only transfer.

Ideas use the existing project event ledger; no schema migration is required. Archive/restore checks the latest saved revision and cannot overwrite another device's intervening state change. Project events refresh the Ideas list on connected devices, with periodic reconciliation. Saved concepts survive browser reloads and conversation deletion. Up to 200 latest ideas are listed; the creative helper receives up to ten active saved ideas as read-only context, with explicitly marked excerpts over 1,200 characters. They are reference concepts, not automatic execution instructions.

Validation: 28 backend tests for idea persistence, ownership, archive/restore, source validation and the creative-helper boundary; 278 frontend tests; TypeScript, changed-file lint and a production build. Desktop (1440px) and phone (390px) browser checks use a separate database and deterministic text provider. They verify opening chat without microphone access, history scrolling, exact text review, saving, opening Create, reloading and zero jobs. Private screenshots and reports stay under ignored `data/fullscreen-ideas-review/`. These checks do not claim live model-quality or GPU benchmarks. The earlier release-blocking legacy chat-execution test migration remains separate.
